## HazeOver 实际在做什么

它的逻辑很简单：跟着你的前台窗口走。你切换到哪个窗口，那个窗口保持原亮度，其余的按你设定的强度变暗。不用最小化、不用隐藏、不用整理桌面，窗口还摊在那儿，只是不再抢你的注意力。

能调的东西比想象中多。变暗强度和动画速度可以拉；浅色外观和深色外观各存一套设置；快捷键随时开关；拖着文件跨应用的时候按住 Fn 键，调暗会临时取消，松手恢复。接多个显示器时，它能标出哪块屏是当前焦点，也可以选择在每块屏上都高亮窗口。桌面被调用时自动显示出来，不会连桌面图标一起压黑。

它还留了自动化的口子，支持快捷指令、专注模式筛选器和 AppleScript。可以做到按一个组合键同时开 HazeOver、切深色外观、打开勿扰。

适合它的场景很具体。外接 27 寸屏写稿，旁边挂着微信、邮件、三个浏览器标签和访达窗口；财务对账时一边是 Excel 一边是后台系统；夜里改稿嫌白底刺眼，但把整块屏幕亮度调低又看不清正文。这些情况下，明暗对比比任何窗口管理操作都直接。

它不负责排列窗口，也不做分屏增强。你要找的是窗口管理工具，这个不是。

## 真实评价和几个不舒服的地方

媒体侧的评价集中在“简单但有效”。《纽约时报》旗下 Wirecutter 说用它“像给该专注的那一处打了一束聚光灯”；Daring Fireball 的 John Gruber 说它“把这个简单的事做得很漂亮，对 macOS 的日常使用有明显差别”。9to5Mac、CNET 和 Macworld 等媒体都写过它，App Store 也做过编辑推荐。

用户侧的声音更实在。美区 App Store 有一条评论来自一位同时开 Excel、Word、Outlook、终端和多个浏览器的用户，大意是“值每一分钱”，理由是不用思考就知道哪个窗口有键盘焦点。这类好评几乎都出自窗口多、屏幕大的人。

缺点也得说。功能面窄是第一点，它只做调暗，没有窗口排列，也没有分屏。指望一个软件解决桌面混乱的人会失望。

第二点是它减少干扰，但不阻止干扰。通知照样弹，消息照样响，HazeOver 只是让背景不那么亮。

第三点跟强度有关。把变暗拉到高档之后，后台窗口的内容基本读不出来。习惯一边翻参考资料一边写的人，每次回去读都得先切窗口，等于把“同时看两个窗口”这个用法堵死了。

第四点是购买层面的。授权能激活几台 Mac、后续大版本更新是否免费、能不能开发票、退款时限多久，这些在公开页面上我都没有查到明确说法。金额不大，但买之前问一句客服，比事后扯皮省事。
